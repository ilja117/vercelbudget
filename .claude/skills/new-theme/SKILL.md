# Нова тема

Спершу прочитати `DESIGN.md` (палітри, «Глина», правила) і пояснити користувачу, як тема виглядатиме (кольори словами, талісман), до коду.

Тваринна тема `<id>` — 4 місця, без жодного тема вийде «наполовину»:
1. Запис у `SKINS` (`grep -n "var SKINS" public/index.html`, скрипт `#usbudget-theme-engine-js`): id, назва, підпис.
2. Талісман у `mascotSvg` — намальований SVG, не емодзі.
3. Блок змінних `html[data-skin="<id>"] { --g-page … --g-ink … }` у `<style id="usbudget-skins">` (за зразком `hamster`/`mochi`) + візерунок фону.
4. Переклад назви й підпису в `public/i18n.js` (словник `D`, поруч із 'Мочі').

Сезонна палітра місяця: `html.g-seasons[data-season="…"]` міняє лише `--g-shell/--g-pop/--g-nav/--g-page`; монетка з символом місяця — `SYM`/`coinSvg` у `#usbudget-theme-engine-js`; форма — `<style id="usbudget-clay">`.

Правила (не порушувати):
- Форма «Глина» спільна для всіх тем: радіуси 30–38px, без рамок, `--g-clay`/`--g-clay-sm`, Rubik + Nunito.
- Кольори цінників лімітів (зелений/жовтий/кораловий) постійні. Текст на кольорі — `--g-ink` (темне, не чисто чорне). Мін. 12px, контраст AA.
- Рух лише під `html.g-motion` і з `prefers-reduced-motion`.

Перевірка: `npm run css` (якщо нові класи), `npm test`, `SKIN=sk-<id> node tools/preview/shot.cjs dashboard settings` світла й `DARK=1`, uk і en — без помилок; глянути знімки.
