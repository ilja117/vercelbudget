# Реліз

1. Свіже: `git fetch -q origin && git log --oneline HEAD..origin/main`. Є нове → `git merge origin/main`, конфлікти зазвичай лише у версіях — брати наступну.
2. Версія: поточна в `<title>` (`grep -n "<title>" public/index.html`) і `CACHE` у `public/sw.js`. Підняти в обох однаково (латка — Z, нова функція — Y).
3. Новий текст інтерфейсу → переклад у `public/i18n.js` (див. скіл `new-ui`).
4. Нові класи Tailwind → `npm run css`.
5. Перевірки (усе має пройти):
   - `node --check` для змінених `.js/.mjs`; для inline-скриптів — витягти й перевірити або покладатися на `pageerror` у перегляді;
   - `npm test`;
   - скіл `preview-check` (uk і en, без помилок сторінки);
   - ручна звірка чисел, якщо чіпали підрахунки.
6. Документи: змінилась структура/ключі/потоки → `docs/ARCHITECTURE.md`; нова функція для людей → коротко в `README.md`; урок із помилки → рядок у «Досвід» `CLAUDE.md`.
7. Коміт у робочу гілку, `git push -u origin <гілка>`.
8. Спитати кнопками (`AskUserQuestion`) «зливати в main?» з коротким списком змін простими словами (без коду, з прикладом, якщо змінились числа).
9. Після «так»: `git checkout main && git pull && git merge --no-ff <гілка> && git push origin main`, повернутися на гілку. Vercel розгорне сам; телефон оновиться при наступному відкритті.
10. Запропонувати `/compact`.
