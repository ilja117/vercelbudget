# Нова кнопка, картка чи екран

0. До коду — пояснити користувачу простими словами, як це виглядатиме і де стоятиме (він не бачить коду). Для тексту кнопок/помилок можна скіл `design:ux-copy`; для вигляду — `DESIGN.md` і `.impeccable/`.
1. Де код: `index.html` не читати цілком — `grep -n`, потім `sed -n 'A,Bp'`. Карта скриптів — `docs/ARCHITECTURE.md` §4. Нова логіка — в останніх скриптах (`#usbudget-simple`, `#usbudget-nav-v5` або новий `<script id="usbudget-...">` в кінці), а не в старих шарах. `renderAll`/`switchTab` перевизначаються обгортками — підчіплятися через `renderAllV5`/`switchTabV5`.
2. Картка з полями (≥3 полів або form) згорнеться сама через `#usbudget-fold` — одразу ставити `data-fold="0"`, якщо не треба.
3. Картку з єдиною кнопкою «повернути» не ховати, поки є що повертати.
4. Дизайн: токени `--g-*`, форма «Глина», без емодзі, без «картки в картці», мін. 12px. Фіксовані елементи з анімацією центрувати `left:0;right:0;margin:auto`.
5. Текст → переклад у `public/i18n.js`: точний рядок у `D`, змінний — шаблон у `P`. Текст із ` · ` перекладається частинами. Регулярки: `\b` не бачить кирилиці — межу задавати явно `(?=[\s.:]|$)`.
6. Нові класи Tailwind → `npm run css`.
7. Перевірка: скіл `preview-check` (uk і en). Перед злиттям — скіл `release`.
